# Provenance and research boundaries

The current implementation comes from Twitter_Pipeline/Current. It adapts Avantika Tiwari's earlier pipeline; Vinay's legacy LLM work is a separate track. The repository structure and public sample were prepared with AI assistance, without changing original project folders. Historical notebook output was cleared for release.

Research data is not bundled because public visibility of social media is not a blanket redistribution grant. Authorize access to incident datasets, archives, boundaries and model weights independently. The included seven-row example contains invented text and synthetic IDs; its coordinates and polygon exist only to exercise code paths. It must not be described as real social media evidence.

The public tests use the actual extraction, timestamp, coverage and label-validation functions. They do not call a real model. The separately preserved research suite was originally recorded with 50 tests and needs the full local configuration; that number is not the count of newly added public tests. Full archive labeling, a human benchmark and cluster performance remain future work.

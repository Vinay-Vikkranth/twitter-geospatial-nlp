# Data layout

`sample/` contains only synthetic demonstration records. These do not describe real people or locations and cannot establish scientific performance.

`private/` is a local-only copy of the original research inputs and selected recorded outputs. It is ignored by Git and is not included on GitHub. Do not add it to a commit.

`research/` is also ignored. Authorized researchers may restore inputs here according to docs/REPRODUCIBILITY.md. Do not substitute synthetic data into historical results or assume a redistribution license for enriched demographic data, social media archives, boundaries, or model weights.

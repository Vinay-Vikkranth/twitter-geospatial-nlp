# Attribution and reuse

Portfolio curation by Vinay Vikkranth Subramanian, based on ASU Quark Lab research with Dr. Asish Satpathy. The work is collaborative; repository ownership does not imply sole authorship. The Twitter expanded pipeline adapts Avantika Tiwari's source work.

No blanket open source license is applied to collaborative research code or third party inputs because a grant covering all material has not been established. Public visibility permits inspection, not unrestricted redistribution. Contact the authors before reuse. External software retains its own licenses. Restricted research inputs, raw tweets, model weights and unpublished manuscripts are not included.

The sample datasets and newly generated diagrams are explicitly labeled. A sample run is not a reproduction of a published experiment. AI assistance was used to structure this portfolio, write documentation and build reproducible demonstrations; scientific findings are attributed separately.
